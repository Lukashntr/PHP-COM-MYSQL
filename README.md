# PHP-COM-MYSQL

Repositório base para estudos e implementação de integrações entre **PHP**, **COM** e **MySQL**.

## Objetivo

Organizar exemplos e código de referência para conectar aplicações PHP a componentes COM e persistir dados em banco MySQL.

## Requisitos

- PHP 8+ (recomendado)
- MySQL 8+ (ou compatível)
- Ambiente com suporte a COM (normalmente Windows)

No momento, o repositório contém apenas este `README.md`.  
Os arquivos de código podem ser adicionados conforme a evolução do projeto.
